## 🎯 对比设计（正确的公平对比）

### 关键原则

| 维度 | Agent | Our Strategy |
|------|-------|--------------|
| **时间窗口** | [T0, T0+τ] | **相同** [T0, T0+τ] |
| **总交易量** | V 合约 | **相同** V 合约 |
| **交易方向** | Buy/Sell | **相同** Buy/Sell |
| **订单拆分** | Agent 的方式 | **优化** 的方式 |
| **执行价格** | Agent 的实际价格 | **优化** 限价单策略 |

### 对比逻辑

**Agent 执行**：
```
窗口 [09:30, 10:00] 买入 100 合约
- 09:32 买入 20 @ 8795.00
- 09:45 买入 30 @ 8802.50
- 09:58 买入 50 @ 8798.25
→ VWAP: 8799.35
```

**我们的优化策略**：
```
同一窗口 [09:30, 10:00] 买入 100 合约
- 拆分为 6 个 5 分钟 slice
- 每个 slice 下限价单 (open - 1 tick)
- 未成交则在窗口结束时市价单
→ VWAP: 8798.50 (假设)
→ 节省：0.85 ticks/合约
```

### 评估指标

**VWAP (Volume-Weighted Average Price)**:
- **Buy**: VWAP 越低越好
- **Sell**: VWAP 越高越好

**Savings**:
```
Buy:  Savings = (Agent_VWAP - Our_VWAP) × Volume
Sell: Savings = (Our_VWAP - Agent_VWAP) × Volume
```
